# Revisão de Compliance OAB para Conteúdo Jurídico

## Quando usar

Use esta skill antes de publicar ou aprovar:

- Post de LinkedIn, Instagram, X ou Facebook.
- Artigo de blog.
- Newsletter jurídica.
- Roteiro de vídeo ou live.
- Página institucional ou landing page.
- CTA de conteúdo jurídico.
- Material educativo com possível finalidade comercial.

## Objetivo

Reduzir riscos de publicidade irregular na advocacia, especialmente:

- mercantilização;
- captação indevida de clientela;
- promessa de resultado;
- comparação com outros profissionais;
- autopromoção excessiva;
- divulgação de caso/cliente sem cautela;
- sensacionalismo;
- linguagem de urgência artificial;
- oferta direta de serviço jurídico.

## Procedimento

1. Identifique canal, público, objetivo e tipo de conteúdo.
2. Classifique o conteúdo como:
   - informativo;
   - educativo;
   - institucional;
   - promocional;
   - potencialmente irregular.
3. Faça varredura de risco usando `references/checklist-publicidade.md`.
4. Marque trechos problemáticos em tabela.
5. Sugira reescrita sóbria, informativa e técnica.
6. Se o risco for alto, recomende não publicar sem revisão humana.
7. Entregue uma versão revisada quando possível.

## Formato de saída

Use esta estrutura:

1. Diagnóstico geral.
2. Classificação do risco: baixo, médio ou alto.
3. Tabela de achados:
   - trecho;
   - risco;
   - motivo;
   - sugestão de ajuste.
4. Versão revisada.
5. Observações finais para revisão profissional.

## Regras de linguagem

Prefira:

- "conteúdo informativo";
- "avaliação técnica depende do caso concreto";
- "pontos de atenção";
- "riscos jurídicos";
- "boas práticas";
- "análise preventiva".

Evite ou reescreva:

- "garanta";
- "recupere agora";
- "não perca seus direitos";
- "consulta grátis";
- "resultado garantido";
- "o melhor escritório";
- "especialista número um";
- "entre em contato antes que seja tarde";
- "você tem direito a indenização".
