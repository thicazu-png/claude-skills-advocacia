# Perguntas para o cliente ou área de negócio

## Contexto comercial

1. Qual é o objetivo do contrato?
2. Qual parte tem maior poder de barganha?
3. O contrato é estratégico ou substituível?
4. Qual é o valor anual ou total?
5. Há urgência para assinatura?
6. Há dependência operacional do fornecedor ou cliente?

## Dados e tecnologia

1. Haverá tratamento de dados pessoais?
2. Quais categorias de dados serão tratadas?
3. Haverá dados sensíveis?
4. Haverá transferência internacional?
5. O fornecedor usará suboperadores?
6. Há exigência de segurança, certificações ou auditoria?
7. O serviço é crítico para a operação?

## Propriedade intelectual

1. Haverá desenvolvimento sob encomenda?
2. Quem deve ser titular dos entregáveis?
3. Haverá uso de código aberto?
4. O fornecedor reutilizará componentes?
5. Há materiais pré-existentes do cliente?

## Operação e saída

1. Como ocorrerá implantação?
2. Há critérios de aceite?
3. Há suporte e SLA?
4. Como os dados serão devolvidos ou eliminados ao término?
5. Há plano de transição?
6. Qual é o custo de saída?

## Risco e aprovação

1. Qual risco é inegociável?
2. Quais pontos podem ser concedidos?
3. Quem aprova exceções?
4. Há política interna de contratação?
5. Há matriz de alçadas?
