# Componentes de Visual Law

## Bloco de conceito

Use para explicar o que é um instituto, regra ou risco.

Estrutura:

- título;
- definição curta;
- exemplo genérico;
- ressalva.

## Bloco de decisão

Use para orientar escolha.

Estrutura:

- pergunta;
- critérios;
- consequência;
- próxima ação.

## Bloco de risco

Use para sinalizar atenção sem alarmismo.

Estrutura:

- risco;
- causa comum;
- impacto possível;
- medida preventiva.

## Bloco de checklist

Use perguntas objetivas, preferencialmente respondidas com sim/não.

Estrutura:

- item;
- por que importa;
- documento ou evidência esperada.

## Bloco de ressalva

Use sempre que houver risco de interpretação como orientação individual.

Modelo:

Este material tem finalidade informativa. A aplicação depende dos fatos, documentos e contexto do caso concreto.

## Hierarquia visual sugerida

1. Título principal: tese ou pergunta.
2. Subtítulo: contexto.
3. Blocos: critérios, riscos ou etapas.
4. Destaque: conclusão prática.
5. Rodapé: ressalva e fonte, quando houver.

## Linguagem visual

- Use no máximo 3 níveis de destaque.
- Evite excesso de cores.
- Use ícones apenas quando ajudarem a compreensão.
- Prefira tabelas simples a longos parágrafos.
- Use espaços em branco para separar ideias.
